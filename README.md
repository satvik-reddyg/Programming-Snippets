## Getting Started

### Clone the Repository

```bash
git clone https://github.com/satvik-reddyg/Programming-Snippets.git
cd Programming-Snippets
```

### Folder Structure

```
Programming-Snippets/
├── Python/
│   ├── fibonacci.py
│   ├── prime_checker.py
│   └── palindrome_checker.py
├── Java/
│   ├── BubbleSort.java
│   ├── BinarySearch.java
│   └── Calculator.java
├── JavaScript/
│   ├── array_methods.js
│   ├── fetch_api.js
│   └── timer.js
└── README.md
```

### Running Examples

**Python:**
```python
python Python/fibonacci.py
```

**Java:**
```bash
javac Java/BubbleSort.java
java BubbleSort
```

**JavaScript:**
```bash
node JavaScript/array_methods.js
```
